
# diseaseWatch

## Description

This package provides functions to assist public health analysts in calculating disease metrics, identifying trends, and generating consolidated reports. 

## Installation

You can install the development version of diseaseWatch from [GitHub](https://github.com/) with: 

``` r
# install.packages("devtools")
devtools::install_github("avantika-sahoo/diseaseWatch")
```

Load the package with:

``` r
library(diseaseWatch)
```
Basic example code:

``` r
library(diseaseWatch)
## basic example code
```
